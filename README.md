# CartoonScrapper

Scraper web para recopilar información de caricaturas.

> Proyecto en etapa inicial.

_Por definir (lenguaje, versión, dependencias)._

## Instalación

```bash
git clone https://github.com/eduricharte/CartoonScrapper.git
cd CartoonScrapper
```

## Configuración

Las credenciales y tokens van en un archivo `.env` local, que está en `.gitignore` y **no se sube** al repositorio. Usa un `.env.example` (sin valores reales) como plantilla.
